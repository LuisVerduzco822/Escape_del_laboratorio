This folder contains only the five original no-anti-aliasing PNG tilesets
used by the game. Their image content is unchanged; unused pack files
(individual tiles, alternative versions, previews and editor sources)
are omitted. The game uses AtlasTexture regions from these tilesets. The atlas-region mapping lives
in game/scripts/PadGlyphs.gd.
