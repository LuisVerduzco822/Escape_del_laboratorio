# Servidor de Escape del Laboratorio

API REST y panel web. Ver la guía completa en `../docs/GUIA_POSTGRESQL.md` y la API en `../docs/API.md`.

```
cp .env.example .env     # edita DATABASE_URL y ADMIN_PASSWORD
npm install
npm start                # http://localhost:3000
npm test                 # requiere TEST_DATABASE_URL (base vacía de pruebas)
```
